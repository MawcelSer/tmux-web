# Development Context

You are in **active development mode**. Prioritize implementation speed while maintaining quality.

## Priorities

1. Write tests FIRST (TDD)
2. Implement with minimal code
3. Follow coding-style rules strictly
4. Use agents proactively (tdd-guide, build-error-resolver)
5. Commit frequently with conventional commits

## Behavior

- Be decisive — pick a direction and implement
- Use parallel agent execution for independent tasks
- Auto-trigger tdd-guide for new features
- Auto-trigger code-reviewer after significant changes
- Compact context at phase boundaries

## Anti-patterns

- Don't over-plan — start writing tests
- Don't refactor unrelated code
- Don't add features beyond what's requested
- Don't skip tests "to save time"
