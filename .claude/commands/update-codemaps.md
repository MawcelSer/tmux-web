# Update Codemaps

Refresh the code mapping data for the project.

## Steps

1. Scan the entire codebase structure
2. Map file relationships and dependencies:
   - Import/export graphs
   - Module boundaries
   - Entry points
3. Identify key files:
   - Configuration files
   - Main entry points
   - Shared utilities
   - Test files
4. Update the internal code map for better navigation

## Usage

```
/update-codemaps
```
