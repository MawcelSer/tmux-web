# Learn

Research unfamiliar patterns, libraries, or APIs before making changes.

## Steps

1. Identify the knowledge gap (library, pattern, API, framework feature)
2. Search the codebase for existing usage patterns
3. Read relevant documentation and source code
4. Summarize findings:
   - What it does
   - How it's used in this project
   - Common patterns and pitfalls
   - Relevant API surface
5. Apply the knowledge to the current task

## Arguments

$ARGUMENTS: The topic, library, or pattern to research

## Usage

```
/learn How does the auth middleware work in this project?
/learn Zod schema validation patterns
/learn React Server Components data fetching
```
