# Instinct Export

Export your learned instincts and patterns for sharing.

## Steps

1. Read the learned skills directory
2. Package all instincts into an exportable format
3. Save to the specified output path
4. Report exported patterns

## Arguments

$ARGUMENTS: Optional — output path (defaults to `./exported-instincts.json`)

## Usage

```
/instinct-export
/instinct-export ./team-shared/my-instincts.json
```
