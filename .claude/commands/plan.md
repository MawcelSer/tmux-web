# Plan

Create a structured implementation plan for the requested feature or task.

## Steps

1. Launch the **planner** agent to analyze the request
2. Explore the codebase to understand current state and affected areas
3. Break the work into ordered phases with dependencies
4. Assess risks and flag unknowns for each phase
5. Output the plan using TodoWrite for tracking

## Arguments

$ARGUMENTS: Description of the feature or task to plan

## Usage

```
/plan Add user authentication with OAuth2 support
/plan Refactor the payment module to support multiple providers
```
