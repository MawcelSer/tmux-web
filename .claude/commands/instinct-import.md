# Instinct Import

Import instincts and learned patterns from an external source.

## Steps

1. Read the specified instinct file or directory
2. Validate the instinct format and structure
3. Merge with existing instincts (skip duplicates)
4. Report imported patterns

## Arguments

$ARGUMENTS: Path to instinct file or directory to import

## Usage

```
/instinct-import ./shared-instincts/
/instinct-import teammate-instincts.json
```
